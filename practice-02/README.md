## Модель и функции

| Поле | Правило |
| --- | --- |
| id | Положительное безопасное целое число, уникальное в списке |
| title | Строка; после trim длина 1–100, внутренние пробелы сохранены |
| completed | Только boolean; новая задача всегда false |
| priority | low, medium или high; по умолчанию medium |

`data.js` содержит наборы, `task-service.js` — девять функций, `main.js` — сценарий. Сервис не читает DOM и не импортирует конкретные наборы.

`createTask` возвращает `{ ok: true, task }`. Операции изменения — `{ ok: true, tasks }`. При предусмотренной ошибке возвращается `{ ok: false, error }`, состояние не заменяется.

Поиск использует `find` и строгое сравнение. Отбор — `filter`, названия — `map`. Добавление использует spread массива, обновление — `map` и spread объекта, удаление — `filter`. Входные массивы и свойства записей сохраняются.

`id` не равен индексу: у задачи id 4 в общем наборе индекс 1. Процент возвращается числом без округления; `toFixed(1)` используется в сценарии для вывода. При обновлении создаются новый массив и новый объект выбранной задачи, остальные записи могут сохранять ссылки.
